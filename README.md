# Automatic Street Light using Arduino

## 📌 Project Overview

This project is an Arduino-based automatic street light system that uses an LDR sensor to detect the surrounding light intensity.

## ⚙️ Working

* During bright light, the LED remains OFF.
* During low light, the LED automatically turns ON.
* The LDR sensor continuously detects the light intensity.

## 🛠️ Components Used

* Arduino Uno
* LDR Sensor
* LED
* 10kΩ Resistor
* 220Ω Resistor
* Breadboard
* Jumper Wires

## 💻 Programming

The project is programmed using Arduino C/C++.

## 🎯 Applications

* Automatic street lighting
* Energy-saving lighting systems
* Smart lighting applications

## 🚀 Future Improvements

The system can be extended using IoT technology for remote monitoring and control.
